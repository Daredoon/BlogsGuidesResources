### 1. Ankiweb
[Ankiweb.com](https://www.ankiweb.com) is flashcard oriented website to remember topics related to language learning. Physics, Maths, Chemistry, English and even Music. Best way to test yourself everyday with choice to determine what your level is between try again, hard, good and easy. Each of these choice gives your time to revise the flash cards which you are don't fully remember yet. It is open source and free.


### 2. Distrowatch

[Distrowatch.com](https://www.distrowatch.com) is a great website to check out and see which linux operating system (OS) is trending. It also gives you news and information about different linux distro and their download link (.iso). Great to check out if you testing different linux distro. 

Personally, I am currently using Arch linux based CachyOS which is awesome. It is fast and looks great. I have installed almost 1320 packages using AUR, Pacman, Gem(for ruby and jekyll) and flatpack. Idling my system uses around 2 GB of RAM. I have also installed VPN. It is a paid subcription. I installed the servers provided by them using clash. It automatically connect whenever i start my system and I can use it's UI in the browser like jupyter notebook. There I can change servers, if the current selected serve is not working.

Coming back to the topic of Distrowatch. I found that CachyOS was trending at top of the list. SO I downlaoded it and using it. It come preinstalled with everything you need and occupies around 18 GB of ssd space.

### 3. Github

[Github.com](https://www.github.com) is git website to create git repositorys and version control of your project. I currently use it for blogs, portfolio, git repository for my projects.

### 4. Kaggle

[Kaggle.com](https://www.kaggle.com) provides a machine learning and deep learning environment with enough hardware to conduct small to medium experiments. Great website to learn machine learning and even do projects. Just upload your dataset and you are good to go. Just be aware that you have 30 hour of GPU time and 20 hour of TPU time every week which i think for free is not a bad deal. Actually i think it is a steal😂. Go try it!

### 5. Websites that will help you learn linux faster while playing games

- [overthewire](https://overthewire.org/)

### 6. Free Online Linux Terminals  
- **[JSLinux](https://bellard.org/jslinux/)** – A full Linux terminal emulator running in your browser (supports multiple distros).  
- **[Webminal](https://www.webminal.org/)** – Free interactive Linux terminal with built-in lessons.  
- **[Copy.sh Linux VM](https://copy.sh/v86/)** – Browser-based virtual machine with Linux terminal access.  
- **[JS/UNIX Terminal](https://github.com/humphd/browser-shell)** – A JavaScript-based Unix-like terminal.  
- **[OnWorks](https://www.onworks.net/)** – Provides free Linux servers with terminal access.  

### 7. Linux Learning Platforms with Terminals  
- **[Linuxzoo](https://linuxzoo.net/)** – Offers real Linux root shells for practice.  
- **[OverTheWire Bandit](http://overthewire.org/wargames/bandit/)** – A game-based SSH terminal for learning Linux security.  
- **[Katacoda (Archived but still works)](https://www.katacoda.com/courses/linux/playground)** – Formerly provided free Linux terminals (some instances still functional).  

### 8. Browser-Based Shells for Quick Testing**  
- **[ShellCheck](https://www.shellcheck.net/)** – Not a full terminal, but great for Bash script validation.  
- **[ExplainShell](https://explainshell.com/)** – Helps understand Linux commands (no execution).  

### 9. Free Cloud-Based Linux Terminals  
- **[Google Cloud Shell](https://shell.cloud.google.com/)** – Free Linux terminal with 5GB storage (requires Google account).  
- **[E2E Networks Jupyter Terminal](https://my.e2enetworks.com/)** – Offers a free cloud-based Linux shell.
